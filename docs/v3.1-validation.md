# v3.1 Firewall Summary Validation

## Local Fixture Coverage

The Docker fixture in `tests/wp-cli/seed-wordfence-fixtures.php` creates a supported `wfBlockedIPLog` shape with:

- `unixday`
- `blockType`
- `blockCount`

It also keeps the existing `wfHits` source populated separately. The fixture is intentionally split so the two data models differ:

| Metric family | 24h | 7d | 30d |
| --- | ---: | ---: | ---: |
| `blocked_hit_rows_window` | 88 | 395 | n/a |
| `firewall_blocks_window` total | 503 | 1,342 | 5,854 |

The Firewall Summary category values are:

| Category | 24h | 7d | 30d |
| --- | ---: | ---: | ---: |
| `complex` | 52 | 121 | 627 |
| `brute_force` | 451 | 1,221 | 5,227 |
| `blocklist` | 0 | 0 | 0 |
| `other` | 0 | 0 | 0 |

The local smoke test asserts the emitted category values and the explicit hit-row aliases. Totals are derived in PromQL with:

```promql
sum by (site, window) (
  wordpress_wordfence_firewall_blocks_window
)
```

## Supported Source Variant

The implemented source variant is `wfblockediplog-unixday-blocktype-blockcount`, resolved through the active WordPress database prefix and existing Wordfence table discovery. It uses bounded category mapping in `Simula_Security_Telemetry_Wordfence_Collector::firewall_block_category()`.

The collector follows Wordfence's observed aggregate query shape for 24-hour, 7-day, and 30-day reporting windows using `unixday` day buckets and `SUM(blockCount)`.

## Real-Site Acceptance Gate

The contract's real-site validation remains an external acceptance gate. For a controlled WordPress/Wordfence instance, record:

- WordPress timezone
- PHP timezone
- database timezone
- Wordfence version
- Simula plugin version
- Wordfence license tier
- Wordfence UI capture timestamp
- exporter collection timestamp
- exported `firewall_blocks_window` category values
- exported `blocked_hit_rows_window` values

Then compare the summed Firewall Summary categories with the Wordfence UI for the same reporting periods. Repeat across a day boundary and, where feasible, a week or month boundary.
