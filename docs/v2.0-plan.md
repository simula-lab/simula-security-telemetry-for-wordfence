# v2.0 Implementation Plan

## Summary

Version 2.0 turns Simula Security Metrics Exporter for Wordfence into an ops-ready WordPress security telemetry exporter. It keeps the node_exporter textfile collector model, adds ready-to-import Grafana and Prometheus assets, supports WP-CLI operation, emits optional JSON Lines incidents, exports freshness and posture metrics, and separates fast activity collection from slow posture collection.

## Key Changes

- Bump plugin metadata and WordPress.org stable tag to `2.0.0`.
- Change the default fast export interval to 15 minutes.
- Add a slow collector interval for scan, 2FA, WordPress posture, and Wordfence posture metrics.
- Add WP-CLI commands for export, metrics-only export, incidents-only export, cursor reset, and status.
- Add an incident log format setting with backward-compatible `text` output and structured `jsonl` output.
- Ship `examples/grafana/grafana-dashboard-wordfence-security-overview.json` and `examples/prometheus/wordfence-alerts.yml`.

## Metrics And Interfaces

- Preserve existing v1 metric names except `error_info`, which now uses a bounded `type` label instead of raw error text.
- Add source freshness metrics for latest hit, latest blocked hit, latest scan timestamp, and scan age.
- Add Wordfence posture metrics for installation, version, firewall, live traffic, scan, and license state.
- Add WordPress posture metrics for core/plugin/theme updates and administrator 2FA coverage.
- Keep top attack source metrics capped to top 10 countries and top 10 normalized IP ranges.

## Test Plan

- Run PHP syntax checks on plugin PHP files.
- Validate Grafana dashboard JSON and Prometheus alert YAML parse successfully.
- Test settings migration from v1-shaped options by verifying new defaults fill in without losing existing values.
- Test cron registration, interval changes, deactivation cleanup, and uninstall cleanup.
- Test WP-CLI export/status/reset paths in a WordPress environment with WP-CLI available.
- Test text and JSONL incident output with representative Wordfence hit rows.
- Verify README/readme.txt metric lists match the exported metric families.

## Assumptions

- The plugin remains file-output based and does not expose a public metrics endpoint.
- Slow metrics can be cached in plugin state so fast exports keep the Prometheus file complete.
- Detailed error messages belong in plugin state and admin/WP-CLI status, not Prometheus labels.
